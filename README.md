### 🍽️ Food Recipe Website

A static web application to explore, view, and search for food recipes using HTML, CSS, and JavaScript.

Features:

List of various food recipes  
 Search functionality by recipe name or ingredient  
 Display recipe image, ingredients, and cooking instructions  
Responsive design for mobile, tablet, and desktop  
 Add recipes to favorites (stored in `localStorage`)  
 Clean, modern UI using only vanilla CSS  
 No frameworks or libraries used  



Tech Used:

  HTML5** – Structure and content  
  CSS3** – Styling and layout  
  JavaScript (Vanilla)** – Interactivity and dynamic content
